# Web Scraper & CSV Exporter (Python)

# ENG

A simple and efficient web scraper built in Python. The script collects structured data from a website and exports it to a CSV file ready for use in Excel.

 Features
- Sends HTTP requests with a customized `User-Agent` to bypass basic restrictions.
- Parses and processes HTML code using `BeautifulSoup4`.
- Robust HTTP error handling.
- Exports data in CSV format (`utf-8-sig`) for correct character encoding in Excel.

 Technologies
- **Python 3.10+**
- **requests** — HTTP requests
- **beautifulsoup4** — HTML parsing
- **csv** — tabular data handling
